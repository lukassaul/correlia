About Correlia

A multi-scale geographic correlation database for exploring how indicators move together across places and time.

What Correlia is

Correlia is a curated, open-access database that joins statistical indicators from authoritative sources to a canonical geographic hierarchy. It lets researchers ask questions like "what correlates with alcohol consumption?" across dozens or hundreds of indicators, at the country, regional, and city level.

The database is served at correlia.org. The API is read-only and public. Every observation is traceable to a citable source with a declared license.

Why it exists

Statistical data is collected on widely different geographic units and time periods. Country-level GDP, city-level consumption, regional health outcomes, and local price surveys all live in separate silos, keyed to incompatible identifiers. This makes correlation studies hard, and it makes it easy to mistake an artifact of aggregation for a real relationship.

Correlia addresses this by:

  • Anchoring every observation to a canonical place in a nested hierarchy (country → admin1 → admin2 → city).
  • Recording the geographic level at which data was actually collected, so the same query can be run at multiple scales and compared.
  • Preserving provenance and license information for every source.
  • Making multi-scale queries trivial, which is the diagnostic for Simpson's Paradox and other scale-dependent artifacts.

Data sources and licensing

Correlia only loads data from sources whose licenses permit public redistribution. The current sources are:

  • GeoNames — geographic backbone, CC BY 4.0.
  • World Bank World Development Indicators — CC BY 4.0.
  • WHO Global Health Observatory — CC BY 4.0.

Each source's license is recorded in the database and surfaced through the API. Sources that do not permit redistribution, or whose terms restrict it, are not loaded into the public database even when they are freely accessible to individual researchers.

A note on correlation and causation. Correlia is a hypothesis-generation tool, not a causal inference engine. Exploratory scans across many indicators will produce false positives by design; this is a property of multiple testing, not a defect of the database. The tested field in scan responses reports how many hypotheses were examined. Robust correlations across scales are still not proof of a causal relationship.

How to contribute

Contributions are welcome from researchers, institutions, and automated agents. All submissions must conform to the contribution contract, which requires canonical geographic identifiers, explicit support levels, declared units, and provenance. See CONTRIBUTING.md for the full specification.

The code, schema, and loaders are on GitHub.

For data providers

If you represent an organization that publishes geographic or statistical data and you are interested in having it indexed by Correlia, please get in touch. We are particularly interested in datasets with subnational coverage (regional, city, or finer), and in data whose license permits public redistribution.
